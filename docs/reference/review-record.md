## 仍需保留的边界

- 启动脚本、已有实验记录和远端实际运行是不同证据层次。
- Pro 结果表还需绑定数据、checkpoint 和 run。
- 不把其他项目的规模与效率数字写成 Pro 成果。
- 不把支持偏好对导出写成已完成 DPO／KTO／在线 RL。
- 不把整体通过率提高写成所有子能力提高。
- 不把“按 group 切分”写成已自动完成全部用户／会话／规则隔离。
