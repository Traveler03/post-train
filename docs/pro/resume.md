## 四条展开版

### Pro 主链路 Agent 数据建设与后训练

面向邮件、日历及 Drive／Docs／Slides 等个人办公场景，独立负责 Pro 主链路的数据建设与 LoRA SFT 流程，优化多轮工具调用、复杂任务执行及授权判断能力。

- **训练数据建设：** 分析线上执行轨迹的任务分布、工具覆盖与失败模式，完成主 Agent 行为归属、当前轮轨迹抽取及质量筛选；针对文档编辑、演示文稿操作和权限管理等低覆盖能力，基于可执行环境合成任务，通过多轮 Rollout 与 LLM 判官拒绝采样构建训练数据。
- **行为与质量设计：** 围绕工具选择、参数正确性、真实执行和结果交付设计筛选标准，构造“明确授权后执行”和“未授权高风险操作前确认”等情境，并对齐工具版本、文件身份及上下文依赖，减少无效轨迹和错误监督。
- **LoRA SFT 实现：** 基于 Megatron-Bridge 独立搭建 DeepSeek MoE 的 LoRA SFT 流程，支持约 98k 长上下文训练；完成工具调用格式、历史轮 loss mask、结束标记及 LoRA 挂载适配，采用整轨迹渲染减少逐轮重复前缀，并实现支持分段隔离的窗口化数据格式；v7 实际完成 276 步、约 2 epoch，最终 checkpoint 保存成功。
- **模型效果：** 在已记录的同 Low Thinking 档位评测中，后训练模型在 Drive／Docs／Slides 上的通过率分别提升 4.93／5.03／3.22 个百分点。

## 30 秒开场

> 我独立负责 Pro 个人办公助手的数据建设与 LoRA SFT，主要优化多轮工具调用中的复杂操作、授权判断和任务完成能力。我从线上轨迹分析能力缺口，再基于可执行环境构造任务，通过 Rollout 和筛选获得训练数据。训练侧负责轨迹转换、监督掩码、LoRA 适配和长上下文训练，最后结合办公任务评测分析收益与退化。

## 90 秒展开

> Pro 主要处理邮件、日历、文档和文件管理等办公请求。这些任务通常需要连续调用工具，模型既要找到正确对象，也要理解当前用户是否已经授权具体操作。
>
> 我独立负责数据合成和 LoRA SFT。数据侧先分析线上执行轨迹，区分主 Agent 动作、历史上下文和平台过程，识别目标操作的覆盖缺口。针对复杂编辑、权限等场景，我基于可执行环境构造任务，让 Agent 实际执行，再通过规则和判官筛选形成训练数据。
>
> 训练侧，我重点处理多轮监督边界。历史和工具返回作为上下文，当前任务中选中的模型动作参与监督；同时完成工具调用格式、LoRA 挂点和长上下文打包适配。整轨迹处理可以减少重复编码，但还要检查前缀、监督位置以及每步监督 token 数。
>
> 最后通过固定思考档位和工具环境下的任务评测分析结果，同时关注提升和退化案例，再调整数据覆盖与训练配方。

## 如何选面试展开点

准备三个本人最熟悉的案例：

1. **数据案例：** 为什么某类任务需要合成，环境和标准怎样定义。
2. **训练案例：** 一次 mask、格式、LoRA 挂点或长上下文问题的定位。
3. **实验案例：** 一组有效对照，包含改善、退化及仍不能下结论的部分。

每个案例都按“问题、依据、修改、验证”展开。详细追问见[面试准备](interview.md)，效果来源见[评测与结果](evaluation.md)。
