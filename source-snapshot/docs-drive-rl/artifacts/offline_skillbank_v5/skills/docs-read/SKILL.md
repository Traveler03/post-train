# docs-read

以最少的只读操作解析目标文档和请求范围，取得对应视图，向用户返回准确、完整且可追溯的结果。

## 工作流

1. **understand_request**：提取文档标识、请求视图、限定章节或关键词、输出语言与格式；保留多语言及特殊字符，不擅自改写其语义。（适用条件：所有文档读取请求）
2. **resolve_target**：通过标题、链接、资源标识或上下文解析具体文档。可容忍无意义的空格和排版差异，但应核对标题与类型；候选不唯一时先消歧。（适用条件：尚未唯一确定目标文档）
3. **read_requested_view**：按请求选择正文、结构、元数据、评论或指定章节视图，只读取完成任务所需的范围。长文或返回被截断时，继续定位并取得目标片段，不能仅凭截断提示推断答案。（适用条件：用户要求搜索结果之外的文档信息）
4. **extract_and_check**：从读取结果中提取所需事实，复核数字、比例、单位、币种、时间表达、章节边界及多语言翻译；未在证据中出现的限定信息保持未知。（适用条件：已取得请求视图）
5. **respond**：按照用户要求直接呈现内容、结构、元数据或答案；限定章节请求不得混入其他章节。证据不完整时明确说明已取得和未取得的部分，不宣称完整完成。（适用条件：准备生成用户可见回复）

## 决策规则

- 文件名、搜索摘要和普通元数据不能替代正文或指定视图的读取证据。
- 标题中的语言、字符方向、括号、连接符等应原样保留；仅将无语义的空格或排版差异用于匹配，不得把不同标题强行视为同一文档。
- 多个候选均可能匹配且上下文不足时，不任意选择；应进一步核对或请用户确认。
- 请求正文时读取正文，请求段落或章节结构时读取结构，请求元数据或评论时读取对应视图。
- 请求指定章节或关键词时，以标题、段落边界或相邻上下文确认命中范围，避免把同名词的其他位置当作目标。
- 结构回答只报告证据中可见的标题、段落层级和顺序，不依据标题臆造章节内容。
- 数字、百分比、金额和单位按原文保留；原文未注明币种、年份或其他限定时不得补充。
- 翻译时间和行动项时保持原文的相对关系与不确定性，不把“下周前”等表达改成无依据的具体日期或错误周期。
- 遇到截断、缺页或视图不足时继续获取目标证据；仍无法取得则如实说明，禁止从未显示部分猜测。
- 本任务默认只读，不得创建、编辑、删除、移动、共享文档，也不得代替用户创建日历或其他外部事项。
- 最终回复不得包含内部推理、隐藏标签、工具调试信息或未闭合的展示结构。

## 停止条件

- 目标文档已唯一解析，请求视图及范围已取得，关键事实完成核对，并已给出用户可见答案。
- 目标文档或必要视图在合理的只读重试后仍不可访问，此时说明阻碍和已确认的信息后停止。
- 存在无法安全消除的候选歧义，需要用户补充信息时停止并请求澄清。
- 后续操作将超出读取授权或涉及写入时立即停止，不执行该操作。

## 失败恢复

- 未找到目标时，使用保留原语义的标题形式重试，例如处理多余空格、常见排版差异或字符方向问题；不要随意删除有意义字符。
- 出现多个候选时，比较完整标题、文档类型和可用上下文；仍无法唯一确定则列出最少必要差异并请求确认。
- 正文过长或结果截断时，改为按关键词、章节、段落范围或其他等价只读方式获取目标附近内容。
- 所选视图不能回答问题时，切换到与请求语义对应的另一只读视图，而不是重复无信息增益的无效调用。
- 读取失败或权限不足时，可进行一次参数与资源身份核对；仍失败则明确告知无法验证，不生成猜测答案。
- 作答前若发现数字、单位、币种、时间或翻译无法由原文支持，应回看证据并删除无依据补充。


## 验收边界

策略说明与验收逻辑独立维护。执行任务时遵循本文件；需要判断任务中间状态时读取
[`state_template.json`](state_template.json)，需要语义判分时读取
[`judge_rubric.md`](judge_rubric.md)。等价工具可作为同一状态的不同证据，不能把工具调用本身当作状态完成。
